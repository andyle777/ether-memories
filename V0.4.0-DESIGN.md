# Ether Memories v0.4.0 — Portable Recall Layer

The 0.4 release adds validated transactional snapshot imports, injectable
`StoragePort` adapters, crash-safer filesystem replacement, stable graph edge
identities, clone-on-read public results, opt-in graph-assisted recall, and
provider-neutral portable records.

The library schema remains `ether.memory_store.v0.3` and the context schema
remains `ether.memory_context.v1`. Portable records use
`ether.portable_record.v1`. `StoragePort` assumes a single logical writer
unless the adapter provides stronger concurrency guarantees.
