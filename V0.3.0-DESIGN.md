# Ether Memories v0.3.0 — Design Record

This release merges the three-foundation civilian memory spine with a provider-neutral AI transport layer.

## Three foundations
- Memory Notes
- Diary
- Mind Graph

## Processing
- CondensationEngine

## AI transport
`MemoryContext` is a bounded, versioned projection of durable memory. It is not a second database and is never used as the persistence format.

## Consumer exits
- Plain JSON
- Agent tool result
- RLM environment
- Future RAG and provider adapters

## Hard fence
No vectors, embeddings, LLM dependency, autonomous memory decisions, personality model, distributed sync, agent network, self-modification, or Aether runtime installation.

## Release status
Design target: v0.3.0. This archive is the clean source package intended for local verification before any GitHub publication.
